# 2026-10-28 개발 일기

다른 프로젝트를 진행하느라 중단했던 AI Love Workout 작업을 다시 시작했다. SourceTree에서 Fetch/Pull과 작업 트리 확인을 진행하고, Codex로 현재 저장소 전체를 분석했다.

작업 시작 시점의 분석에서는 실행 가능한 서비스 코드가 없고 요구사항과 ADR 등 문서 중심으로 진행되어 있음을 확인했다. 기존 개발 일정을 2026-11-01까지의 취업 포트폴리오 MVP 일정으로 조정하고, 러닝과 맨몸운동을 1차 구현 대상으로 정했다.

웨이트와 일부 기능은 후속 구현으로 유예하되 기존 승인 요구사항은 보존하기로 했다. 일정이 짧아져도 기존 SDD 방식과 문서 운영 원칙을 유지한다.

범위 확정 후 최소 Domain Model, ERD와 API 설계 문서를 작성했다. 이어서 React / Spring Boot / FastAPI / PostgreSQL 실행 골격을 구축했다. 설치된 JDK 21로 실행하면서 Java 컴파일 대상은 17로 유지했다.

구축한 환경은 Docker Compose에서 네 서비스를 통합 실행해 검증했다. Spring Boot Health와 Dependencies Health, FastAPI Health 및 Vite 프록시를 통한 Spring Boot → FastAPI/DB 연결을 확인했다. PostgreSQL 17.11에서 실제 쿼리도 성공했다.

구축 단계의 검증에서 Spring Boot 자동 테스트 8개와 FastAPI 자동 테스트 3개가 통과했고, React 타입 검사와 빌드도 성공했다. AI 서비스를 일시 중지했을 때 Dependencies Health가 503을 반환하고 재시작 후 UP으로 복구되는 것도 확인했다. 검증 후에는 검증용 컨테이너만 중지하고 데이터 볼륨은 보존했다.
