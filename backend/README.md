# Backend

Spring Boot API server for authentication, workout management, statistics, and AI service integration.

헬스 API·연결 점검과 AUTH / USER 기능을 제공한다. 실행·테스트는 [개발 환경 안내](../docs/development.md)를 따른다. JDK 21에서 Gradle Wrapper를 실행하며 Java 컴파일 대상은 17이다. POSTGRES_PASSWORD와 JWT_SECRET 환경 변수가 필요하고 스키마는 Flyway로 관리한다.
